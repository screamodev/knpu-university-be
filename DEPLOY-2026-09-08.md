# Правки 08.09

Другий набір правок за документом клієнта. Код у `origin/dev` обох репозиторіїв, сервер **B**
(`193.105.7.20`, SSH `:10163`).

Що їде:

- нове поле `documents.group` — підзаголовки всередині одного розділу документів;
- новий розділ документів «Звіти Студентського Парламенту» і блок під нього на `/student/council`;
- 21 файл: угоди й договори кафедри спеціальної педагогіки, звіти парламенту, плани заходів
  Центру інклюзивної освіти;
- рубрика «Навчально-методичний інклюзивний центр» і два анонси конференцій;
- меню «Навчання» без колонки «Форми навчання», плитка «Антикорупція» веде на гугл-сайт відділу;
- сторінка профспілки студентів наповнена;
- кафедра ТМПФВ: прибрано дубль «Головної» і дві картки.


## 3. Схема

```bash
cd /root/knpu-university-be/migration
DRUN="docker run --rm --network webnet -e DIRECTUS_URL -e DIRECTUS_TOKEN -v $(pwd):/w"
IMG="python:3.12-slim python"

$DRUN -w /w/schema $IMG apply_schema.py --dry-run
```

Має надрукувати рівно три рядки:

```
+ field documents.group
+ field documents.groupEn
+ documents.section: student-council-reports
```

Якщо там щось іще — зупиніться й напишіть, що саме. Далі:

```bash
$DRUN -w /w/schema $IMG apply_schema.py
```

## 8. Перевірка

```bash
# меню «Навчання»: «Форми навчання» і «Заочна форма» зникли, Moodle і практика лишились
for s in "Форми навчання" "Заочна форма" "Практична підготовка" Moodle; do
  printf '%-24s ' "$s"; curl -s http://localhost:3000/ | grep -c "$s"
done

# «Антикорупція» у «Швидкому доступі» веде на гугл-сайт
curl -s http://localhost:3000/ | grep -c 'sites.google.com/view/khnpuanticorupcia'

# підзаголовки графіка
curl -s http://localhost:3000/education/schedule | grep -o 'Денна форма\|Заочна форма\|Накази' | sort | uniq -c

# профспілка і звіти парламенту
curl -s http://localhost:3000/student/union | grep -c 'Сідак Анастасія Сергіївна'
curl -s http://localhost:3000/student/council | grep -c 'Звіти Студентського Парламенту'

# угоди кафедри спеціальної педагогіки — усі 16 файлів віддаються
curl -s http://localhost:3000/university/structure/kafedra-specialnoyi-pedagogiky/cooperation \
  | grep -o '/assets/[0-9a-f-]\{36\}' | sort -u | while read a; do
    printf '%s ' "$a"; curl -s -o /dev/null -w '%{http_code}\n' "http://localhost:8055$a"; done

# конференції та рубрика
curl -s 'http://localhost:8055/items/science_conferences?filter[isUpcoming][_eq]=true&fields=title'
curl -s 'http://localhost:8055/items/categories?filter[slug][_eq]=navchalno-metodychnyi-inklyuzyvnyi-tsentr&fields=name'
```

Очима: `https://hnpu.edu.ua/education/schedule` — список розбитий на «Денна форма», «Заочна
форма» і «Накази»; `https://hnpu.edu.ua/student/union` — фото й контакти голови;
`https://hnpu.edu.ua/university/structure/kafedra-teoriyi-metodyky-i-praktyky-fizychnogo-vyhovannya`
— один блок «Головна», а не два.

## Відкат

Зміни в Directus відкочуються ревізіями (History у картці рядка), фронт — попереднім образом.
Поле `documents.group` порожнє за замовчуванням, тож навіть якщо його лишити, списки
виглядають як раніше.
