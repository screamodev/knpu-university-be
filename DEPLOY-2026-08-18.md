# Деплой на прод — зміни від 18.08.2026

Самодостатня інструкція: тільки те, що треба зробити після `git pull` у **обох** репозиторіях.
Попередні частини (`DEPLOY-PROD.md`, `DEPLOY-2026-08-08.md`) повторювати не потрібно.

Що їде: правки за списком зауважень (пункти 1–14 і 21), центр забезпечення якості з поверненим
форматуванням старого сайту, вартість навчання, ухвали вченої ради, «На допомогу здобувачу»,
сторінки освітніх програм і дисциплін вільного вибору, перенесення кафедри біології, чистка
кафедральних сторінок.

**Перед стартом**

```bash
export DIRECTUS_URL=http://knpu-university-directus:8055
export DIRECTUS_TOKEN=…        # статичний токен адміністратора
```

Адреса внутрішня: публічний домен іде через Cloudflare, який рве довгі завантаження. Усі
python-команди — у контейнері `python:3.12-slim` **з `--network webnet`** і обов'язково з
`-e DIRECTUS_URL -e DIRECTUS_TOKEN`.

Скрипти ідемпотентні: перерваний прогін просто запускається ще раз. `files.map.json` на проді
свій — не копіювати з локальної машини.

## 4. Дані

Порядок важливий лише для моніторингу: спершу `resync` (він виправляє напрям і назви наявних
анкет), потім `load` (додає ті, яких ще немає). Решта — у будь-якому порядку.

```bash
cd migration/pass2
RUN='docker run --rm --network webnet -e DIRECTUS_URL -e DIRECTUS_TOKEN
     -v '"$(pwd)"':/w -w /w python:3.12-slim python'

# 4.1 моніторинг: 32 анкети змінюють напрям, 10 додаються
$RUN resync_monitoring.py --dry-run
$RUN resync_monitoring.py
$RUN load.py data/monitoring.json

# 4.2 решта документів
$RUN load.py data/monitoring-extra.json      # «Політика у сфері якості»
$RUN load.py data/council-decisions.json     # 83 ухвали вченої ради 2017–2026
$RUN load.py data/candidate-support.json     # «На допомогу здобувачу» + вчене звання
$RUN load.py data/tuition.json               # наказ 82-од і таблиці вартості
$RUN load.py data/quality-centre-extra.json  # «Положення про центр забезпечення якості освіти»
```

Кілька `download failed: 404` — очікувано: ці файли старий сайт уже не віддає (2 ухвали з 85,
програма анкети № 37, положення про разові ради, 8 файлів результатів анкет). Вони перелічені у
звіті клієнту.

## 5. Файли, на які посилається перенесений текст

Контент прийшов із git уже з `/assets/<uuid>`, тож качати нема з чого — файли доливаються під
тими самими uuid із карт. Без цього кроку фото на сторінках (волонтерство, кафедри, центр якості)
віддаватимуть 403.

```bash

$RUN sync_files_map.py --map ../smc/images.map.json
```
