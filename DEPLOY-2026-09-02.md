# Викочування: ДВВ магістратури 2026/2028

Одна правка, але з великим вантажем файлів: на сторінці
`/education/free-choice/master` над блоком «2025/2026 навчальний рік» з'явився такий самий
блок «2026/2028 навчальний рік» — два списки, що розкриваються («Цикл загальної підготовки»
і «Цикл професійної підготовки»), 61 дисципліна, до кожної опис і презентація. Це 119 PDF,
близько 300 МБ, які клієнт віддав текою на Google Drive.

Код у `origin/dev` обох репозиторіїв. Сервер **B** (`193.105.7.20`, SSH `:10163`).

Порядок обов'язковий: спершу файли, потім фронт. Якщо зробити навпаки, сторінка кілька
хвилин показуватиме посилання на ще не залиті `/assets/…`.

**Перед стартом**

```bash
export DIRECTUS_URL=http://knpu-university-directus:8055
export DIRECTUS_TOKEN=…        # статичний токен адміністратора
```

Як і раніше: адреса внутрішня (Cloudflare рве довгі завантаження), python-команди — у
контейнері `python:3.12-slim` з `--network webnet`, монтуємо **всю** `migration/`.

## 1. Бекап і місце на диску

Файли лягають двічі: спершу в `migration/dvv-2026/files/`, потім у сховище Directus. Треба
близько 700 МБ вільного місця; після заливання тимчасову теку прибираємо (крок 4).

```bash
/root/backup-directus.sh && ls -lht /root/backups | head -3
df -h /
```

## 2. Оновити репозиторії

```bash
cd /root/knpu-university-be && git pull
cd /root/knpu-university-fe && git pull
```

## 3. Залити 119 PDF у Directus

Скрипт сам качає теку з Google Drive (вона публічна) і заливає кожен файл під тим самим
uuid, що вже стоїть у тексті сторінки. Ідемпотентний — перерваний прогін просто запускається
ще раз, уже залите пропускається.

```bash
cd /root/knpu-university-be/migration
DRUN="docker run --rm --network webnet -e DIRECTUS_URL -e DIRECTUS_TOKEN -v $(pwd):/w"
IMG="python:3.12-slim python"

$DRUN -w /w/dvv-2026 $IMG push_assets.py --dry-run | tail -3
```

Має написати `119 у карті · 0 уже на цілі · 119 залити`. Далі — саме заливання, це 10–25
хвилин разом із качанням, тож під `screen`:

```bash
screen -S dvv
cd /root/knpu-university-be/migration
docker run --rm --network webnet -e DIRECTUS_URL -e DIRECTUS_TOKEN -v "$(pwd)":/w \
  -w /w/dvv-2026 python:3.12-slim python push_assets.py
```

Вийти зі `screen` — `Ctrl+A`, `D`; повернутися — `screen -r dvv`. Наприкінці має бути
`uploaded=119 failed=0`. Якщо щось впало — просто повторити команду.

> Найважчий файл, `P_Orhaniz_osvitn_protsesu_v_pochat_shkoli.pdf`, важить 102 МБ. Google на
> таких віддає сторінку «Virus scan warning» — скрипт її проходить сам, але саме цей файл
> качається найдовше.

Якщо канал до Google із сервера повільний, файли можна перекинути з ноутбука:

```bash
# з локальної машини
rsync -avP -e 'ssh -p 10163' knpu-university-be/migration/dvv-2026/files/ \
  root@193.105.7.20:/root/knpu-university-be/migration/dvv-2026/files/
```

— і тоді `push_assets.py` нічого не качатиме.

## 4. Прибрати тимчасову теку

```bash
du -sh /root/knpu-university-be/migration/dvv-2026/files
rm -rf /root/knpu-university-be/migration/dvv-2026/files
df -h /
```

Тека в `.gitignore`, тож `git pull` на неї не скаржитиметься.

## 5. Перезібрати фронт

Перелік лежить у статичному контенті фронту, тож потрібен білд. Збірка не переживає
`screen -d -m` (процес виходить одразу і `up -d` бере старий образ) — тільки `nohup`:

```bash
cd /root/knpu-university-fe
nohup docker compose -f docker-compose.prod.yml -f docker-compose.host.yml build app \
  > /root/fe-build.log 2>&1 &
tail -f /root/fe-build.log        # вийти Ctrl+C, білд триває
```

Коли добіжить — звірити, що образ свіжий, і підняти:

```bash
docker images knpu-university-fe --format '{{.Repository}} {{.CreatedSince}}'
docker compose -f docker-compose.prod.yml -f docker-compose.host.yml up -d --force-recreate app
sleep 20
```

## 6. Перевірка

```bash
curl -s -o /dev/null -w '%{http_code}\n' http://localhost:3000/education/free-choice/master

# усі 119 файлів на місці й віддаються
python3 - <<'PY'
import json, urllib.request
files = json.load(open('/root/knpu-university-be/migration/dvv-2026/files.map.json'))
bad = []
for uuid, meta in files.items():
    try:
        request = urllib.request.Request(f'http://localhost:8055/assets/{uuid}', method='HEAD')
        with urllib.request.urlopen(request, timeout=30) as response:
            if response.status != 200:
                bad.append(meta['name'])
    except Exception as exc:
        bad.append(f"{meta['name']}: {exc}")
print(len(files), 'у карті ·', len(bad), 'битих')
print('\n'.join(bad[:10]))
PY
```

Очима на `https://hnpu.edu.ua/education/free-choice/master`: перший заголовок —
«2026/2028 навчальний рік», під ним два списки, що розкриваються; нижче, як і було,
«2025/2026 навчальний рік» зі своїми двома списками. У новому «Циклі загальної підготовки»
17 дисциплін, у «Циклі професійної підготовки» — 44. Назва дисципліни відкриває опис,
кафедра в дужках — презентацію.

## Відкат

Файли можна лишити (вони нікому не заважають), досить відкотити фронт:

```bash
cd /root/knpu-university-fe && git log --oneline -5
git checkout <попередній sha>
nohup docker compose -f docker-compose.prod.yml -f docker-compose.host.yml build app \
  > /root/fe-build.log 2>&1 &
```

Якщо треба прибрати й файли — `push_assets.py` їх не видаляє, це робиться в адмінці
(Files → тека, куди вони лягли) або запитом до `/files` за списком uuid із карти.
