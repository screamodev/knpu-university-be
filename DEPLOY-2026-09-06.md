# Пілот: тексти вкладок підрозділів у Directus

Перша частина роботи, яку просив клієнт: щоб редактор правив тексти на сторінках підрозділів,
факультетів і кафедр сам, без розробника й складання образу.

Що їде:

- нова колекція **`structure_pages`** — один рядок на вкладку одного підрозділу;
- **`kafedra-horeografiyi`** як пілот: 5 вкладок перенесено в базу;
- фронт читає вкладку з Directus, а якщо рядка немає або Directus недоступний — показує
  мігрований текст із бандла, як раніше;
- у тілі сторінки запрацювали згорнуті блоки `<details>`.

Решта 36 підрозділів **не змінюється** — вони й далі беруть текст зі статики. Це головна
властивість пілота: якщо щось піде не так, досить видалити 5 рядків в адмінці.

Код у `origin/dev` обох репозиторіїв. Сервер **B** (`193.105.7.20`, SSH `:10163`).

**Перед стартом**

```bash
export DIRECTUS_URL=http://knpu-university-directus:8055
export DIRECTUS_TOKEN=…        # статичний токен адміністратора
```

Адреса внутрішня: публічний домен іде через Cloudflare, який рве довгі запити. Python-команди —
у контейнері `python:3.12-slim` з `--network webnet`, монтуємо **всю** `migration/`, робочу теку
задає `-w` **до** імені образу.

## 1. Бекап

```bash
/root/backup-directus.sh && ls -lht /root/backups | head -3
```

## 2. Оновити репозиторії

```bash
cd /root/knpu-university-be && git pull
cd /root/knpu-university-fe && git pull
```

## 3. Створити колекцію

```bash
cd /root/knpu-university-be/migration
DRUN="docker run --rm --network webnet -e DIRECTUS_URL -e DIRECTUS_TOKEN -v $(pwd):/w"
IMG="python:3.12-slim python"

$DRUN -w /w/schema $IMG apply_schema.py --dry-run
```

Має надрукувати рівно один рядок — `+ collection structure_pages`. Якщо там щось іще, зупиніться
й напишіть, що саме. Далі:

```bash
$DRUN -w /w/schema $IMG apply_schema.py
```

> `schema apply` зі снапшота тут **не запускаємо**: на цій версії Directus повторний apply падає
> на `drop not null` для uuid-первинних ключів. Схему котить `apply_schema.py`.
>
> Снапшот `snapshots/schema.yaml` цього разу теж не перегенеровано: локальна база відстає від
> закоміченого файла (у ньому є розділи документів і напрями моніторингу, додані на проді
> запитом до Postgres), і перегенерація з локалі мовчки їх би зтерла. Джерело правди для
> `structure_pages` — `migration/schema/apply_schema.py`.

## 4. Права

Обов'язково після зміни схеми: `apply_schema.py` створює колекцію, але не роздає до неї доступ.
Без цього кроку редактор не побачить колекцію, а анонім — опублікованих рядків.

```bash
cd /root/knpu-university-be
docker compose -f docker-compose.prod.yml -f docker-compose.host.yml exec \
  -e PUBLIC_URL=http://127.0.0.1:8055 directus sh /directus/snapshots/bootstrap-public-access.sh
docker compose -f docker-compose.prod.yml -f docker-compose.host.yml exec \
  -e PUBLIC_URL=http://127.0.0.1:8055 directus sh /directus/snapshots/bootstrap-editor-role.sh
```

`127.0.0.1`, а не `localhost`: BusyBox резолвить `localhost` у `::1`, на якому Directus не слухає.

У виводі мають бути рядки `+ read on structure_pages` і чотири `+ create/read/update/delete on
structure_pages`.

## 5. Залити 5 вкладок пілота

```bash
cd /root/knpu-university-be/migration
$DRUN -w /w $IMG pass2/load.py structure-pages/data/structure-pages.json --dry-run
$DRUN -w /w $IMG pass2/load.py structure-pages/data/structure-pages.json
```

Очікувано: `structure_pages 5 rows`, потім `created=5 skipped=0 failed=0`. Завантажувач
пропускає рядки, які вже є, тож повторний запуск безпечний.

> `9_export_to_directus.py` тут **не запускаємо**: він читає статичний контент із сусіднього
> репозиторію `knpu-university-fe`, а в контейнер змонтована сама `migration/`. Конверт
> `data/structure-pages.json` закомічено — його готують на машині розробника, коли додають
> черговий підрозділ.

## 6. Перезібрати фронт

Тільки через `nohup`: зі `screen -d -m` процес виходить одразу і `up -d` бере старий образ.

```bash
cd /root/knpu-university-fe

  > /root/fe-build.log 2>&1 &

```

```bash

docker compose -f docker-compose.prod.yml -f docker-compose.host.yml up -d --force-recreate app
sleep 20
```

## 7. Перевірка

```bash
for t in "" /admission /education /science /cooperation; do
  printf '%-14s ' "${t:-home}"
  curl -s -o /dev/null -w '%{http_code}\n' \
    "http://localhost:3000/university/structure/kafedra-horeografiyi$t"
done

# сусідній, непереміщений підрозділ має працювати як раніше
curl -s -o /dev/null -w 'kafedra-informatyky %{http_code}\n' \
  http://localhost:3000/university/structure/kafedra-informatyky/education

# рядки на місці й видні аноніму
curl -s 'http://localhost:8055/items/structure_pages?fields=unit_slug,tab,status&limit=-1'
```

Усе — `200`, у колекції п'ять опублікованих рядків.

Очима на `https://hnpu.edu.ua/university/structure/kafedra-horeografiyi/education`: текст той
самий, що був до міграції.

**Головна перевірка — та, заради якої все робилося.** Зайти в адмінку під роллю Editor →
колекція «Тексти вкладок підрозділів» → `kafedra-horeografiyi · education` → змінити слово в
полі «Текст вкладки українською» → зберегти → оновити сторінку. Зміна має бути на сайті одразу,
без складання.

Там же перевірити згорнутий блок: кнопкою «код» вставити

```html
<details><summary>Перевірка</summary><p>Текст усередині.</p></details>
```

— на сайті це має стати блоком, що розкривається, а не зникнути й не лишитися голим текстом.
Після перевірки прибрати.

## Що редактор поки що не може

Свідомо не входить у пілот, щоб було що показати вже зараз:

- **Прев'ю чернетки.** Чернетка не публікується, побачити її на сайті не можна — правимо й
  публікуємо, відкат через ревізії Directus (History у картці рядка).
- **Картки керівництва** (54 особи в 11 підрозділах) і **посилання під текстом** лишаються у
  статиці. Експорт відмовляється чіпати підрозділ із картками, щоб не втратити їх мовчки.
- **Пошук по сайту** індексується на складанні зі статичних файлів, тож правки редактора
  потраплять у пошук лише після наступного білду.
- Решта 36 підрозділів. Переносяться тією ж командою з кроку 5, по одному слагу.

## Відкат

Видалити п'ять рядків — сайт одразу повернеться до мігрованого тексту, фронт перезбирати не
треба:

```bash
docker run --rm --network webnet -e DIRECTUS_URL -e DIRECTUS_TOKEN python:3.12-slim python - <<'PY'
import json, os, urllib.request
base, token = os.environ['DIRECTUS_URL'].rstrip('/'), os.environ['DIRECTUS_TOKEN']
def api(method, path, payload=None):
    request = urllib.request.Request(
        base + path, method=method,
        data=json.dumps(payload).encode() if payload is not None else None,
        headers={'Authorization': f'Bearer {token}', 'Content-Type': 'application/json'})
    with urllib.request.urlopen(request, timeout=60) as response:
        body = response.read()
    return json.loads(body)['data'] if body else None
rows = api('GET', '/items/structure_pages?fields=id,unit_slug&limit=-1') or []
ids = [row['id'] for row in rows if row['unit_slug'] == 'kafedra-horeografiyi']
api('DELETE', '/items/structure_pages', ids)
print('deleted', len(ids))
PY
```

Колекцію при цьому можна лишити — порожня, вона нікому не заважає.
