Документ клієнта `Сайт_2025-2026.docx` (Google Drive `1ThtAvsNnEwDii-9blynFTsZt5-2cYaKQ`):
35 заходів з вересня 2025 по червень 2026, до кожного текст і 1–3 фото (разом 38).
Розміщено у вкладці «Наука» → «ХРОНІКА НАУКОВИХ ЗАХОДІВ» сторінки
`/university/structure/ukrainian-philology/science`, **у тому ж вигляді, що й наявні записи**:
рядок «дата. назва» з посиланням на одностраничну PDF-картку (дата й назва, фото, текст).
Раніше такі картки лежали на Drive, ці 35 лежать файлами Directus (`/assets/<uuid>`).

## Що в бандлі

- `files/` — 35 PDF-карток (16:9, градієнтний фон, як у наявних); `files.map.json` — детерміновані
  uuid5 (`https://hnpu.edu.ua/migration/fixes-2026-10-05-chronicle`);
- `push_assets.py` — заливає їх у Directus (ідемпотентний);
- `chronicle-events.json` — дата, назва, файл і uuid кожної картки (з нього зібрано HTML хроніки).

Фронт: `app/content/structure/ukrainian-philology/science.uk.json` — блок «2025/2026 навчальний рік»
з 35 рядками після запису 07.03.2023. Рядки відсортовано за датою, не за порядком у документі.

## Що уточнити в клієнта

- Заголовків у документі майже немає: назви взято дослівно з підписів на колажах, з тексту заходу
  або з наявних заголовків; **«Вебінар професора Анатолія Миколайовича Нелюби» (25.02.2026) — моє
  формулювання**, бо ні заголовка, ні підпису на колажі немає;
- «Перші кроки у науку» — у тексті лише «У цю суботу», без дати, тому рядок без дати;
- «Міжнародний день грамотності»: у документі «8 вересня», а захід відбувся 10 вересня 2025
  (дату взято з тексту);
- тиждень рідної мови (17–21.02) подано одним записом, «День науки» (16.05) — одним записом разом зі
  списком заходів тижня 7–15 травня, як у документі;
- частину заходів вже є у вкладці «Студенти» → «Студентське життя» (наприклад, лекція Наталі Вотсон,
  вивчення словників);
- емодзі та невидимі символи з документа прибрано (шрифт PDF їх не тримає).

## Як накотити на прод

Бекап не обовʼязковий: бандл лише додає файли в Directus, наявні дані не змінює.

```bash
cd /root/knpu-university-be && git pull
set -a; . ./.env; set +a
cd migration
DRUN() { docker run --rm --network webnet \
  -e DIRECTUS_URL=http://knpu-university-directus:8055 \
  -e DIRECTUS_EMAIL="$ADMIN_EMAIL" -e DIRECTUS_PASSWORD="$ADMIN_PASSWORD" \
  -e DIRECTUS_TOKEN= \
  -v /root/knpu-university-be/migration:/m -w /m python:3.12-slim python3 "$@"; }
DRUN fixes-2026-10-05-chronicle/push_assets.py --dry-run   # 35 залити
DRUN fixes-2026-10-05-chronicle/push_assets.py
```

Потім фронт: `cd /root/knpu-university-fe && git pull`, `build app`, `up -d --force-recreate app`.
