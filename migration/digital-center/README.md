# Центр цифровізації освіти (`/education/digital-center`)

Друга ітерація сторінки центру — за фідбеком клієнта її переробили під макет сторінки кафедри:
тіло з випадаючими списками, картка контактів і «Оголошення» збоку, новини центру внизу.

| Крок | Скрипт | Вхід | Вихід |
|---|---|---|---|
| 1 | `1_build_body.py` | `source/body.uk.html` | `app/content/pages/digital-center.{uk,en}.json` |
| 2 | `2_news.py` | нода 33348 у легасі-MySQL | 35 рядків `articles` + категорія в Directus |

## 1. Тіло сторінки

`source/body.uk.html` — тіло сторінки зі старого сайту з живими `[collapse]`-шорткодами.
Файл закомічений, а не тягнеться по HTTP: Cloudflare ріже скриптові запити до hnpu.edu.ua
(див. `../legacy-news`), а версія клієнта свіжіша за SQL-дамп — у ній є Наказ №251 (11.2024)
і всі напрями діяльності вже загорнуті у списки.

Що робить скрипт:

- `[collapse title=…]` → секція з `collapsible: true`; вкладений рівень («Стажування на платформі
  Moodle» всередині «Платформа MOODLE») → `children`. Рендерить це `SharedStaticPageBody`
  через `SharedAccordion`;
- `<h2>` у вільній розмітці стає `section.heading` («Оголошення», «Напрями діяльності»);
- чистить HTML через `../structure-pages/2_transform.py` — той самий підмножинний allow-list,
  що приймає санітайзер фронтенду;
- англійська версія: вступ із `hnpu.edu.ua/en/division/education-digitalisation-center`
  (єдиний англомовний абзац, який там був) + перекладені заголовки списків. Тіла лишаються
  українськими — усі документи і форми за ними україномовні.

Правки контенту робіть у `source/body.uk.html` і перезапускайте скрипт, а не в JSON.

Файли, які раніше залили в Directus (`documents`, секція `digital-center`), у джерелі вже
вказані як `/assets/<uuid>` — це чинні PDF на нашому боці, не легасі-хост.

```bash
export DIRECTUS_URL=http://localhost:8055
export DIRECTUS_EMAIL=admin@example.com DIRECTUS_PASSWORD=admin

python3 1_build_body.py --dry-run     # покаже дерево секцій
python3 1_build_body.py
```

Зображень у тілі більше немає: єдиний банер Moodle зі старого сайту недосяжний зі скрипта
(таймаут), тому його замінили текстовим покликанням на платформу. Якщо колись з'являться —
скрипт заллє їх у Directus і збереже мапу в `images.map.json`, а `../pages/sync_images.py`
перенесе ті самі uuid на прод.

## 2. Новини центру

Старий сайт не мав окремих новинних нод для центру: `division/novyny-centru-cyfrovizaciyi-osvity`
— одна сторінка, всередині якої випадаючий список «Архів новин» із 35 записами, розділеними
`<hr />`. Скрипт ріже його назад на статті:

- дата — з тексту запису («15 грудня 2022р.», «11.01.2021 року»); якщо дати немає, береться
  дата попереднього запису, якщо є лише рік — 31 грудня того року;
- заголовок — жирний рядок на початку запису, інакше перше речення без дати;
- slug — транслітерація заголовка + дата, з числовим суфіксом при збігу;
- тіло — HTML (формат, який пише WYSIWYG), почищений тим самим `2_transform.py`;
- усі 35 статей теґуються категорією `centr-cyfrovizaciyi-osvity` («Центр цифровізації освіти»),
  яку сторінка запитує і для блоку новин, і для сайдбару «Оголошення». Категорія створюється
  на першому запуску.

Картинки в тілах лишаються на старому хості — завантажити їх звідси неможливо (той самий
Cloudflare), і так само зроблено для решти легасі-новин. Обкладинок у цих статей немає,
картки показують плейсхолдер.

```bash
docker ps | grep hnpu-legacy-mysql       # контейнер із дампом, підіймається в ../legacy-news

python3 2_news.py --dry-run              # 35 записів: дата, slug, заголовок
python3 2_news.py --limit 3              # спершу маленька партія
python3 2_news.py
```

Скрипт ідемпотентний — матчинг по `slug`, повторний запуск оновлює наявні статті.

Легасі-дамп є лише на машині розробника, тому готові payload'и закомічені в `articles.json`
(`--emit`), а прод читає їх назад:

```bash
python3 2_news.py --dry-run --emit          # оновити articles.json після правок парсера
python3 2_news.py --from-json articles.json --dry-run
```

## Прод

1. Статті: на сервері, з `knpu-university-be/migration/digital-center`, статичним токеном
   (звичайний логін-токен живе 15 хв):

   ```bash
   docker run --rm --network webnet -v "$PWD":/work -w /work \
     -e DIRECTUS_URL=http://knpu-university-directus:8055 -e DIRECTUS_TOKEN="$PROD_TOKEN" \
     python:3.12-slim python 2_news.py --from-json articles.json --dry-run
   # те саме без --dry-run: 35 статей + категорія centr-cyfrovizaciyi-osvity
   ```

   Скрипт залежить лише від stdlib, окремий образ із залежностями не потрібен.
2. Контент сторінки — закомічені JSON у фронті, окремого прогону на проді не потребує;
   картинок у тілі зараз немає, тож `../pages/sync_images.py` не потрібен.
3. Категорію `centr-cyfrovizaciyi-osvity` створює `2_news.py`; окремо заводити не треба.
4. Фронт перезібрати (`docker compose -f docker-compose.prod.yml build app && … up -d app`) —
   білд заново збирає індекс пошуку зі змінених JSON контенту.
