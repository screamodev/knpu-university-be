# Правки 20.10.2026, п. 2 — бібліографічні покажчики 2017–2019

Документ клієнта «Правки 19.10.26 / 20.10.26», пункт «Бібліографічні покажчики» (Наукова
бібліотека, ТЕРМІНОВО): на `/science/bibliographic-indexes` скопіювати зі старого сайту
(`old.hnpu.edu.ua/uk/bibliografichni-pokazhchyky-naukovoyi-biblioteky-hnpu-imeni-g-s-skovorody`)
покажчики за 2017, 2018 і 2019 роки повністю; за 2020 рік — прибрати покажчик Бойчука.

Сторінка — статичний JSON фронта (`app/content/pages/science-bibliographic-indexes.uk.json`),
у Directus `static_pages` її немає. Тут лежать лише PDF і скрипти.

| Що | Скільки |
| --- | --- |
| PDF зі старого сайту (`files.map.json`, поле `url`) | 14 |
| Блоки на сторінці | 2019 (6 описів, один без файла), 2018 (5), 2017 (4) |

Файли, що качаються зі старого сайту, в git не лежать (`.gitignore`), `push_assets.py` качає їх
сам.

```bash
cd migration
python3 fixes-2026-10-20-bibl/push_assets.py --dry-run   # 14 файлів
python3 fixes-2026-10-20-bibl/push_assets.py
```

## Що зроблено на фронті

`build.py` розбирає стару сторінку, збирає розмітку блоків 2019 → 2017 і вписує її в JSON
(`python3 build.py --apply`; без `--apply` лише перевіряє й пише карту). Розмітка така сама, як
у блоці 2020 року: УДК, ББК і авторський знак — кожен у своєму `<p>`, номер пункту в одному
рядку з УДК, кожен опис у власному `<p>`, заголовки років — `<hr /><p><strong>…</strong></p>`.
Перед записом `build.py` перевіряє баланс тегів, текст поза `<p>`, «осиротілі» номери пунктів
і що кожне `/assets/<uuid>` є в карті файлів. Текст дослівно, схлопнуто лише подвійні пробіли
(«1).» у 2019 році — як на старому сайті).

Заодно полагоджено хвіст сторінки: `<p>` Фрізмана (2020) не був закритий, а заголовок 2019 року
стояв без власного `<p>`.

## Чого тут немає і чому

- **Лозова В. І. (2019, біобібліографія, вип. 2).** Опис перенесено без посилання: файл
  `lozova_biobibliograf.pdf` на старому сайті віддає 404. Потрібен файл від клієнта.
- **Покажчик Бойчука за 2020 рік** уже прибрано 24.09 (`fixes-2026-09-24`), тут нічого не міняли.
- Стару сторінку old.hnpu.edu.ua не правимо.
- Про заголовки років 2024–2026 (без `<p>`, текст лежить прямо в блоці) — це давнє, у цьому
  бандлі їх не чіпали.
