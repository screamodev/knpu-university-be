# science-activity — документи Наукової ради та наукових заходів

Пункт 13 списку зауважень від 17.08.2026. Дві сторінки старого сайту дають документи для двох
нових розділів колекції `documents`:

| Розділ | Сторінка на сайті | Джерело |
|---|---|---|
| `science-council` | `/science/council` | https://hnpu.edu.ua/uk/division/naukova-rada |
| `science-events` | блок «Наукові заходи» на `/science/activity` | https://hnpu.edu.ua/uk/division/naukova-ta-naukovo-tehnichna-diyalnist-hnpu-imeni-gs-skovorody |

Перелік документів зашитий у `load.py` (`DOCUMENTS`) — джерел дванадцять, окремий крок extract тут
зайвий. Файли лежать двома способами: PDF на старому сайті (оригінал уже не віддається, тому
беремо через `web.archive.org/.../2024id_/`) і Google Drive (`uc?export=download`, для більших
файлів — `drive.usercontent.google.com/download?...&confirm=t`).

## Запуск

```sh
DIRECTUS_TOKEN=... python3 load.py --dry-run
DIRECTUS_TOKEN=... python3 load.py
```

Ідемпотентно за парою (`section`, `title`); `files.map.json` тримає url → uuid, тож той самий файл
має той самий `/assets/<uuid>` у кожному середовищі. Перед запуском на новому середовищі треба
застосувати схему (`migration/schema/apply_schema.py` додає обидва значення `documents.section`).

## Чого бракує

- **План засідань Наукової ради 2024–2025 і 2023–2024** — обидва лежать на Google Drive із
  доступом «за запитом»: без авторизації віддається сторінка-попередження, а не PDF. Потрібно, щоб
  клієнт відкрив доступ або надіслав файли.
- Клієнт перелічив ще кілька документів блоку «Наукові заходи» (Положення про проведення наукових
  заходів, плани міжнародних, всеукраїнських і регіональних конференцій, круглих столів, «Наукові
  заходи в Україні та за кордоном», архів). На старому сайті сторінки з ними знайти не вдалося —
  потрібні покликання або файли. Редактор може додати їх сам: Документи → «+» → розділ «Наукові
  заходи».
