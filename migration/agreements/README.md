# agreements — реєстр угод про співпрацю

Пункт 6 списку зауважень від 17.08.2026: перенести на новий сайт сторінку
[Угоди про співпрацю](https://hnpu.edu.ua/uk/ugody-pro-spivpracyu-hnpu-imeni-gs-skovorody) —
один документ і п’ять розділів реєстру, «по принципу наказів з основної діяльності».

На старому сайті це п’ять покликань на відкриті Google-документи; у кожному таблиця:
№ · дата укладання · сторони і предмет · термін дії (у міжнародних ще й країна).

## Куди потрапляють дані

Колекція `cooperation_agreements` (створює `migration/schema/apply_schema.py`), поле `category`
розділяє п’ять розділів. Сторінки — `/university/agreements` і п’ять дочірніх маршрутів у
`knpu-university-fe/app/pages/university/agreements/`, спільний компонент `SharedAgreementList`.

## Запуск

```sh
python3 1_extract.py                       # Google Docs → data/agreements.json (466 рядків)
DIRECTUS_TOKEN=... python3 2_load.py --dry-run
DIRECTUS_TOKEN=... python3 2_load.py
```

`1_extract.py` бере документи експортом у `.docx` і читає `word/document.xml` стандартною
бібліотекою — без залежностей. `2_load.py` ідемпотентний за трійкою
(`category`, `number`, `partner`), тож повторний запуск нічого не дублює.

Після заливки на новому середовищі треба перезапустити `snapshots/bootstrap-public-access.sh` —
без цього колекція не читається анонімно і сторінки будуть порожні.

## Що лишилось за клієнтом

Файл самої «Угоди про співпрацю та партнерство між МОН України та ХНПУ імені Г.С. Сковороди» на
старому сайті не опубліковано — на сторінці стоїть лише назва блоку. Поки клієнт не надішле
документ, на сторінці показано тільки заголовок угоди.
