# Правки 14.09.2026 — опис конференції у WYSIWYG

Редактори вставляли посилання на інформаційний лист у `science_conferences.description`, а
сайт показував його текстом. Тепер поле — той самий редактор, що в новинах: посилання, жирний,
списки; картка на `/science/conferences` рендерить HTML.

## Як накотити

```bash
cd migration
python3 fixes-2026-09-14/rich_conference_descriptions.py --dry-run
python3 fixes-2026-09-14/rich_conference_descriptions.py
```

Скрипт перемикає інтерфейс полів `description` і `descriptionEn` і переводить наявні описи з
простого тексту в HTML (рядки → `<br>`, голі адреси → посилання). Уже HTML-описи не чіпає;
повторний запуск нічого не міняє. Фронт уміє показати й старий простий текст, тож порядок
«скрипт ↔ деплой фронту» не важливий.
