# Правки 16.09.2026

PDF «Правки 16.09.2026», 22 пункти, і docx «Аспірантура сайт» (17.09) (п. 3 клієнт позначив як виконаний). Матеріали — з пошти
sitehnpu@hnpu.edu.ua і тек Google Drive, сторінки старого сайту — з old.hnpu.edu.ua.

## Що куди їде

| Що | Куди |
| --- | --- |
| фото кафедр, центрів, ФФВіС, випускників, волонтерства; фото й документи зі старого сайту | медіатека (`push_assets.py`) |
| схема структури станом на 31.08.2026 | `documents`, розділ `university-structure` (`data/fixes-2026-09-16.json`) |
| розділ документів `university-structure`; slug-и `static_pages` для «Науки» й аспірантів-іноземців; вкладки `staff`, `trust`; підрозділи `teacher-competence-centre`, `mental-health-centre` | схема (`apply_schema.py` тепер дописує варіанти до наявних select-полів) |
| вкладка «Аспіранту» (її ведуть в адмінці): посилання на сторінки аспірантів-іноземців і громадян України, без «Дисциплін вільного вибору» | `structure_pages` (`patch_structure_pages.py`) |

Решта — фронт: тексти сторінок, меню «Наука», нові сторінки центрів і розділу «Наука».

## Як накотити

```bash
cd migration
python3 schema/apply_schema.py --dry-run
python3 schema/apply_schema.py

python3 fixes-2026-09-16/push_assets.py --dry-run   # 283 файли
python3 fixes-2026-09-16/push_assets.py

python3 pass2/load.py fixes-2026-09-16/data/fixes-2026-09-16.json --dry-run
python3 pass2/load.py fixes-2026-09-16/data/fixes-2026-09-16.json

python3 fixes-2026-09-16/patch_structure_pages.py --dry-run
python3 fixes-2026-09-16/patch_structure_pages.py
```

Фото стиснуті до 1600 px і лежать у `files/`. Документи старого сайту (~220 МБ, `sci-*.pdf`) у git
немає — `push_assets.py` качає їх з old.hnpu.edu.ua за полем `url` у `files.map.json`.

## Інструменти бандла

* `bundle.py` — uuid5 файлів, стиснення фото, карта файлів.
* `fetch_legacy.py` — сторінка старого сайту → `data/legacy/<key>.html` з `/assets/<uuid>`.
* `doc_to_html.py` — .doc/.docx підрозділу → HTML (посилання-поля Word стають `<a>`).

## Чого тут немає і чому

* **Особиста сторінка Паньок Т. В.** (вкладки «Навчально-методична робота» тощо) — це її Google-сайт,
  не наш.
* **Центр ментального здоров'я: «План заходів», «Новини», «Корисні посилання»** — матеріалів немає;
  «Валеоклуб» перенесено зі старого сайту.
* **Меню «Наука»: «Положення про відділ» (аспірантура; відділ наукової діяльності), «Послуги»
  бібліотеки, «План публікацій на 2026 рік», сторінка «Комісія з академічної доброчесності»** —
  ні посилань, ні текстів у правках немає, на старому сайті таких сторінок теж немає.
* **Новини кафедри соціальної роботи** — клієнт відклав.
* **Аспіранти — іноземні громадяни: розклади групи 2024-1** — у правках без посилань.
