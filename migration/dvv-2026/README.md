# ДВВ магістратури 2026/2028

Перелік дисциплін вільного вибору другого (магістерського) рівня на 2026/2028 навчальний рік:
61 дисципліна (17 у циклі загальної підготовки, 44 — професійної), на кожну два PDF — опис
дисципліни (`T_…`) під назвою і презентація (`P_…`) під кафедрою. Усього 119 унікальних файлів,
бо кілька кафедр дали один опис на кілька дисциплін.

Джерела:

* `ДВВ магістри (2).docx` від клієнта — назви, кафедри, імена файлів;
* [тека на Google Drive](https://drive.google.com/drive/folders/1XnShR-svy8i20WlmPo_-3DpdS5MmqCL2) — самі PDF.

## Що тут лежить

| файл | що це |
| --- | --- |
| `disciplines.json` | дисципліна → цикл, кафедра, імена двох файлів |
| `files.map.json` | uuid у Directus → ім'я файла, його id на Drive і розмір |
| `push_assets.py` | качає з Drive те, чого немає в `files/`, і заливає в Directus під тим самим uuid |
| `render_sections.py` | збирає секції сторінки «Здобувачу» в `knpu-university-fe` |

Самі PDF (~300 МБ) у git не лежать — `files/` в `.gitignore`, скрипт качає їх сам.
uuid детерміновані (`uuid5` від імені файла), тож `/assets/<uuid>` у тексті сторінки
однаковий на локалі й на проді.

## Як накотити

```bash
cd migration/dvv-2026
export DIRECTUS_URL=http://localhost:8055        # на проді — https://admin.hnpu.edu.ua
export DIRECTUS_TOKEN=…                          # або DIRECTUS_EMAIL / DIRECTUS_PASSWORD
python3 push_assets.py --dry-run                 # показати, чого бракує
python3 push_assets.py
```

Ідемпотентний: що вже є на цілі — пропускає, тож повторний запуск безпечний. Качання всієї
теки — близько 300 МБ, на повільному каналі краще пустити під `screen`/`nohup`.

`render_sections.py` уже відпрацював, його результат закомічено в
`knpu-university-fe/app/content/pages/quality-centre-students.uk.json`. Запускати
повторно треба лише якщо клієнт пришле оновлений перелік.

## Про що варто пам'ятати

* `P_Orhaniz_osvitn_protsesu_v_pochat_shkoli.pdf` важить 102 МБ — Google на таких віддає
  сторінку «Virus scan warning», скрипт її проходить. На сайті це найважче посилання на
  сторінці; якщо клієнт погодиться, файл варто перетиснути.
* Кафедри в дужках узяті з docx як є, включно з їхньою пунктуацією (десь `,`, десь `;`).
