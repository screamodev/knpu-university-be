# Правки 23.09.2026, п. 6 — біобібліографічні покажчики

Документ клієнта «Правки 23.09.26», пункт 6 (Наукова бібліотека): на сторінках
«Бібліографічні покажчики» (`/science/bibliographic-indexes`) і «Видатні вчені ХНПУ імені
Г. С. Сковороди» (`/science/notable-scientists`) прибрати покажчики Бойчука Ю. Д. і додати
чотири нові покажчики 2025 року. Обидві сторінки — статичні JSON фронта
(`app/content/pages/science-*.uk.json`), тут лежать лише тексти покажчиків.

| Файл (надіслав клієнт) | Куди |
| --- | --- |
| `bibl-gavrysh-2025.pdf` | Гавриш Ірина Володимирівна |
| `bibl-zelenska-2025.pdf` | Зеленська Людмила Дмитрівна |
| `bibl-kozina-2025.pdf` | Козіна Жаннета Леонідівна |
| `bibl-popova-o-2025.pdf` | Попова Олена Володимирівна |

Кожен файл — на обох сторінках: опис у розділі 2025 року «Бібліографічних покажчиків» і
ПІБ у списку «Видатних вчених».

## Що зроблено на фронті (без бандла)

- `science-bibliographic-indexes.uk.json`: у розділі 2025 року прибрано Бойчука (2-ге вид.),
  одразу після «Біобібліографічні покажчики» додано описи з docx клієнта в порядку Гавриш,
  Зеленська, Козіна, Попова; у розділі 2020 року прибрано Бойчука, Фрізман перенумерований
  на `1)`. У описі Гавриш прибрано подвоєне «УДК УДК».
- `science-notable-scientists.uk.json`: прибрано «Бойчук Юрій Дмитрович 1 видання /
  2 видання», нові ПІБ вставлено за вказаними клієнтом місцями.
