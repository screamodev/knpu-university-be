# files-tree — розкладання файлосховища по теках

Клієнт попросив дерево тек замість одного спільного простору і запитав, чи можна це зробити з
файлами, які вже завантажено. Можна: тека — це поле `folder` рядка `directus_files`, файл не
перезаписується і не переїжджає в сховищі, тому кожне покликання `/assets/<uuid>` — зокрема ті,
що вже вшиті в перенесений HTML — працює далі.

## Дерево

Теки створює `snapshots/bootstrap-editor-experience.sh` (фіксовані UUID, однакові в усіх
середовищах):

```
Новини
Документи
  ├ Накази з основної діяльності
  ├ Університет
  ├ Навчання
  ├ Наука
  ├ Вступ
  └ Студентство
Газета «Учитель»
Медіа сторінок
  ├ Структура підрозділів
  ├ Партнери
  └ Галерея
Архів старого сайту
```

## Як розкладаються файли

`organize_files.py` не гадає за назвою файлу — він дивиться, **що на файл посилається**:

| Джерело | Тека |
|---|---|
| `documents.file` | за `section` (див. `SECTION_FOLDERS`) |
| `university_orders.documentFile` | Документи / Накази з основної діяльності |
| контингент, розклад, моніторинг, акредитація | Документи / Навчання |
| ради, наукові школи | Документи / Наука |
| програми фахових випробувань | Документи / Вступ |
| `newspaper_issues` | Газета «Учитель» |
| `partners.logo`, `gallery_items.image` | Медіа сторінок / … |
| `articles.cover`, вкладення новин | Новини |
| `migration/structure-pages/images.map.json` | Медіа сторінок / Структура підрозділів |
| лише `legacy_redirects.file` | Архів старого сайту |

Файл, на який не посилається ніщо з переліченого, **лишається там, де він є**, і потрапляє в
рядок «unmatched» підсумку — так видно, що саме залишилось поза деревом.

## Запуск

Локально:

```sh
DIRECTUS_URL=http://localhost:8055 DIRECTUS_TOKEN=... python3 organize_files.py --dry-run
DIRECTUS_URL=http://localhost:8055 DIRECTUS_TOKEN=... python3 organize_files.py
```

На проді — статичний токен і внутрішня адреса, як в усіх міграційних скриптах
(`DEPLOY-2026-08-08.md`):

```sh
docker run --rm --network webnet \
  -e DIRECTUS_URL=http://knpu-university-directus:8055 -e DIRECTUS_TOKEN=... \
  -v "$PWD":/w -w /w python:3.12-slim python migration/files-tree/organize_files.py --dry-run
```

Спершу треба, щоб на цьому середовищі відпрацював `bootstrap-editor-experience.sh` — інакше тек
ще немає. Скрипт ідемпотентний: другий запуск дає `to move: 0`. Прапорці: `--dry-run`, `--limit N`,
`--batch N`.
