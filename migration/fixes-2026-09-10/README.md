# Правки 10.09.2026

Четвертий набір правок: PDF «10.09.2026 Срочные» плюс docx «Сайт зміниї (10.09.26)» від Центру
забезпечення якості освіти (обидва прийшли на sitehnpu@hnpu.edu.ua).

## Що куди їде

| Що | Куди |
| --- | --- |
| нова діаграма циклу забезпечення якості | медіатека; `app/content/pages/quality-centre-quality.uk.json`, секція «Якість освіти» |
| 5 PDF з результатами анкет ННІ української філології (2026) | медіатека; та сама сторінка, «Результати анкетування» |
| 3 PDF з результатами анкет ОП «Цифрові технології в професійній освіті» | медіатека; «Результати анкетування» ФМІПО |
| тексти трьох спеціалізованих вчених рад | нова колекція `static_pages` — щоб секретарі самі додавали рядки таблиці захистів |

Схему цього разу чіпати треба: `static_pages` — нова колекція.

## Як накотити

```bash
cd migration
export DIRECTUS_URL=http://knpu-university-directus:8055
export DIRECTUS_EMAIL=… DIRECTUS_PASSWORD=…      # або DIRECTUS_TOKEN

python3 schema/apply_schema.py --dry-run          # має показати створення static_pages
python3 schema/apply_schema.py

python3 fixes-2026-09-10/push_assets.py --dry-run  # 9 файлів
python3 fixes-2026-09-10/push_assets.py

python3 pass2/load.py static-pages/data/static-pages.json --dry-run
python3 pass2/load.py static-pages/data/static-pages.json
```

Файли прийшли поштою, тож їхні байти лежать у `files/` в git — качати під час деплою немає
звідки. uuid детерміновані (uuid5 у просторі `https://hnpu.edu.ua/migration/fixes-2026-09-10`),
тож `/assets/<uuid>` у текстах сторінок збігається на локалі й на проді.

`static-pages/data/static-pages.json` уже згенерований (`static-pages/export_councils.py`).
Повторний запуск `load.py` перетирає тіла рад тим, що мігровано зі старого сайту, — після того
як секретарі почнуть правити сторінки в адмінці, його не ганяють.

## Чого тут немає і чому

* **Динамічна таблиця захистів** — зроблена не окремою колекцією рядків, а WYSIWYG-полем
  `static_pages.body`: клієнт просив саме «додавати рядки таблиці, наповнювати їх текстом і
  вставляти гіперпосилання самим», а це рівно те, що вміє редактор Directus.
* **Пункти 2 і 13 PDF** — це один і той самий docx Центру якості (у листі о 15:37 його
  розширена версія), тож окремого бандла під них немає.
