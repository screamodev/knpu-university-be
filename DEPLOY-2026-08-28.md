# Викочування правок 25.08 і 28.08

Дві порції клієнтських правок: `2026_08_25` (мегаменю, моніторинг, кафедри) і `2026_08_28`
(конференція трудового колективу, гуртожитки, структура). Код уже в `origin/dev` обох
репозиторіїв; тут — що зробити на сервері **B** (`193.105.7.20`, SSH `:10163`).

Порядок має значення: спершу дані (секції документів і напрями анкет), потім фронт — інакше
редактори побачать сторінки без потрібних секцій.

## 1. Бекап

```bash
/root/backup-directus.sh && ls -lht /root/backups | head -3
```

## 2. Дві нові секції документів

`Гуртожитки` (накази про поселення) і `Конференція трудового колективу — ухвали`. Через адмінку
поле `section` не зберігалося, тож пишемо в базу й перечитуємо схему перезапуском Directus:

```bash
cd /root/knpu-university-be && set -a; . ./.env; set +a
docker run --rm -i --network dbnet -e PGPASSWORD="$DB_PASSWORD" postgres:16-alpine \
  psql -h knpu-university-postgres -U "$DB_USER" -d "$DB_DATABASE" <<'SQL'
UPDATE directus_fields
SET options = jsonb_set(options::jsonb, '{choices}',
      (options::jsonb->'choices') || '[{"text":"Гуртожитки","value":"dormitories"},
        {"text":"Конференція трудового колективу — ухвали","value":"staff-conference"}]'::jsonb),
    display_options = jsonb_set(display_options::jsonb, '{choices}',
      (display_options::jsonb->'choices') || '[{"text":"Гуртожитки","value":"dormitories"},
        {"text":"Конференція трудового колективу — ухвали","value":"staff-conference"}]'::jsonb)
WHERE collection = 'documents' AND field = 'section';
SQL
```

## 3. Перерозподіл анкет моніторингу

Вісім нових напрямів замість дванадцяти старих; збіг за номером анкети, підваріанти йдуть за
базовим номером. Те, чого немає в новому переліку (сьогодні це лише анкета №4), лишається в
«Інші дослідження» — зі сторінки нічого не зникає.

```bash
cd /root/knpu-university-be && git pull && set -a; . ./.env; set +a
docker run --rm -i --network dbnet -e PGPASSWORD="$DB_PASSWORD" \
  -v "$PWD/migration/monitoring-2026":/sql postgres:16-alpine \
  psql -h knpu-university-postgres -U "$DB_USER" -d "$DB_DATABASE" \
  -v ON_ERROR_STOP=1 -f /sql/resort-areas.sql
```

Останній `SELECT` у скрипті друкує розподіл — звірити з документом відділу моніторингу.

## 4. Перезапуск Directus

Схема поля кешується в пам'яті; без цього нові секції й напрями в адмінці не з'являться.

```bash
cd /root/knpu-university-be && docker compose -f docker-compose.prod.yml -f docker-compose.host.yml restart directus
sleep 20 && curl -s localhost:8055/server/health; echo
```

Перевірка, що обидві правки лягли:

```bash
curl -sg 'http://localhost:8055/fields/documents/section' | grep -o '"value":"dormitories"\|"value":"staff-conference"' | sort -u
curl -sg 'http://localhost:8055/items/monitoring_surveys?aggregate[count]=id&groupBy[]=area'
```

## 5. Фронт

Складання ~10–15 хвилин, з'їдає ~3 ГБ — своп на місці.

```bash
cd /root/knpu-university-fe && git pull && screen -S build -d -m \
  docker compose -f docker-compose.prod.yml -f docker-compose.host.yml build app
```

Стежити: `screen -r build`, вийти `Ctrl+A`, `D`. Коли добіжить:

```bash
cd /root/knpu-university-fe && docker compose -f docker-compose.prod.yml -f docker-compose.host.yml up -d app
sleep 20
```

## 6. Перевірка

```bash
for u in /university/staff-conference /admissions/dormitories /student/dormitories \
         /student/notable-alumni /university/extra-services /education/student-rating \
         /education/monitoring /science/publishing /university/structure \
         "/education/quality?tab=students"; do
  printf '%-42s ' "$u"; curl -s -o /dev/null -w '%{http_code}\n' "http://localhost:3000$u"
done
```

`/student/dormitories` має віддати `301`, решта — `200`.

Очима на сайті: у мегаменю Наука є колонка «Структура»; «Дисципліни вільного вибору» ведуть на
вкладку центру якості; на `/education/monitoring` вісім заголовків-напрямів і кожна анкета
окремим акордеоном (11 і 22 — по одному); у структурі «Виконавча рада» відкриває план роботи,
«Загальних зборів студентів» немає, «Конференція трудового колективу» веде на свою сторінку.

## 7. Що лишається редакторам

- наказ 150-од → Documents, секція «Гуртожитки»;
- ухвали Конференції → Documents, секція «Конференція трудового колективу — ухвали»;
- анкети №8, №12, №40, №41, №42, №43 → колекція Monitoring surveys (у базі їх немає);
- світлини: викладачі кафедри спеціальної педагогіки, співробітники редакційно-видавничого
  відділу, фото ФМІПО (головна, наука, галерея студентства, «Випуск бакалаврів 2025»),
  хореографія (Єпік, Патлай, Бєляєва), видатні випускники.
