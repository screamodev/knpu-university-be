# Деплой на прод — зміни від 08.08.2026

Самодостатня інструкція: тільки те, що треба зробити після `git pull` у **обох** репозиторіях.
Нічого з попередніх частин `DEPLOY-PROD.md` тут повторювати не потрібно.

Що їде: сторінки 27 кафедр, центр забезпечення якості освіти з дампа (новини + закриті раніше
розділи), студентське самоврядування, 127 наказів, разові вчені ради з редіректами, дерево
категорій новин, пошук по сайту, три розширення адмінки.

**Перед стартом**

```bash
export DIRECTUS_URL=https://hnpu-admin.dev42hub.uk
export DIRECTUS_TOKEN=…        # статичний токен адміністратора: прогони тривають годинами
```

Усі python-команди — з теки `knpu-university-be/migration`, у контейнері
`python:3.12-slim --network host`. Скрипти ідемпотентні: перерваний прогін просто запускається ще
раз. Файли `files.map.json` на проді свої — не копіювати з локальної машини.

не читаються публічно — редіректи й нові сторінки будуть порожні.

## 4. Дані

Запускати по черзі; кожен рядок можна повторити.

```bash
cd migration
RUN="docker run --rm --network host -v $(pwd):/w -e DIRECTUS_URL -e DIRECTUS_TOKEN python:3.12-slim"

# 4.1 зображення сторінок факультетів і кафедр (ідентифікатори ті самі, що у фронтенді)
$RUN -w /w/structure-pages python 3_load_images.py

# 4.2 контент пасу 2: документи, моніторинг, акредитація, контингент, наукові школи й напрями
$RUN -w /w/pass2 sh -c 'for f in data/documents.json data/monitoring.json \
  data/accreditation_certificates.json data/accreditation_dossiers.json data/contingent.json \
  data/science_schools.json data/science_directions.json data/orders.json; do python load.py "$f"; done'

# 4.3 категорії кафедр під факультетськими
$RUN -w /w/pass2 python seed_unit_categories.py

# 4.4 новини центру забезпечення якості освіти (138 записів)
$RUN -w /w/smc python 2_load_news.py

# 4.5 разові вчені ради: 263 ради + ~1 800 документів (~7 ГБ, кілька годин)
$RUN -w /w/razovi-rady python ../pass2/load.py data/councils.json --map files.map.json
$RUN -w /w/razovi-rady python 3_rewrite_bodies.py
$RUN -w /w/razovi-rady sh -c 'python 4_build_redirects.py && python ../pass2/load.py data/legacy_redirects.json'
```

## 5. Файли всередині текстів (~2 300 PDF, довго)

```bash

  --unlink-host smc.hnpu.edu.ua --unlink-missing
$RUN -w /w/pass2 python mirror_page_files.py --content /w/../knpu-university-fe/app/content/structure \
  --unlink-missing
```

> `--content /srv/knpu-university-fe/app/content/pages`.
