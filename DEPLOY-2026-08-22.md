# Деплой на прод — правки від 17.08.2026

Самодостатня інструкція: тільки те, що треба зробити після `git pull` у **обох** репозиторіях.
Попередні частини (`DEPLOY-PROD.md`, `DEPLOY-2026-08-08.md`, `DEPLOY-2026-08-18.md`) повторювати
не потрібно.

Що їде: список зауважень від 17.08.2026 — кнопка переходу на старий сайт, українська як мова за
замовчуванням, розділ «Вступ» на старому сайті, лого Еразмус+, угода з МОН, сторінки служби
ректора й відділу охорони праці, нормативна база освітніх програм, чистка центру забезпечення
якості освіти, рейтинг НПП, сторінки відділу практик, спортивних секцій, кафедри хореографії та
факультету математики, інформатики і природничої освіти.

**Перед стартом**

```bash
export DIRECTUS_URL=http://knpu-university-directus:8055
export DIRECTUS_TOKEN=…        # статичний токен адміністратора
```

Адреса внутрішня: публічний домен іде через Cloudflare, який рве довгі завантаження. Усі
python-команди — у контейнері `python:3.12-slim` **з `--network webnet`** і обов'язково з
`-e DIRECTUS_URL -e DIRECTUS_TOKEN`. Скрипти ідемпотентні: перерваний прогін просто запускається
ще раз.

## 2. Код

```bash
cd knpu-university-be && git pull
cd ../knpu-university-fe && git pull
```

Контент сторінок (`app/content/**`) і зображення Еразмус+ (`public/images/static/erasmus/**`)
приїдуть із `git pull` — генерувати їх на сервері не треба.

## 3. Схема

Додає розділи `documents.section`: силабуси й розклад дисциплін вільного вибору, рейтинг НПП,
спортивний клуб. Без цього кроку рядки документів не збережуться.

```bash
cd ../knpu-university-be/migration/schema
RUN='docker run --rm --network webnet -e DIRECTUS_URL -e DIRECTUS_TOKEN
     -v '"$(pwd)"':/w -w /w python:3.12-slim python'
$RUN apply_schema.py --dry-run
$RUN apply_schema.py
```

## 4. Файли, яких немає на старому сайті

Рейтинги НПП за 2024/2025 і угода з МОН прийшли текою Google Drive, документи спортивного клубу
та рейтинги 2021–2024 — зі старого сайту (він нестабільний, тому лежать у репозиторії). Заливати
**перед** кроком 5: рядки документів посилаються на ці id.

```bash
cd ../drive-assets

     -v '"$(pwd)"':/w -w /w python:3.12-slim python'

$RUN push_assets.py
```
